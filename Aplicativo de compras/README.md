# Fruit Shop prototype

A static client-side shopping prototype built with HTML, CSS, and vanilla JavaScript.

## Run

Open `index.html` in a modern browser. No build step or server is required.

## Pages

- `#/products` — browse the 10 sample fruits and add quantities to the cart.
- `#/product-details?id=1` — view a selected product's details.
- `#/shopping-cart` — update quantities, remove products, and review subtotals.
- `#/checkout` — review the order and simulate processing it.

The cart is saved in the browser's `localStorage`. All products and prices are sample data; checkout does not take payment or submit a real order.
